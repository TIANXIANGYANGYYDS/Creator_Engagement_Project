候选代码的明确收益证据是：可控测试可阻止临期 IP 进入长初始化；两个 16 项短批次对照中，新增 IP 16 → 12，业务可用项均为 31/32。它没有证明真实大批次的成功率、尾延迟或成本必然提高：

- 原实网对照全局并发 4，今天线上全局并发 8，最大批次 2,781 项，负载范围不同。
- 每批提取 2 个会增加供应商调用次数，突发任务可能需要更久才能补足容量。

- 代理优化不能自行解决验证码、访问权限、链接类型不支持或目标页面解析缺失。

因此候选开关继续保持默认关闭；当前证据支持继续验证临期保护和采购策略，不支持直接全量启用后保证无退化。
