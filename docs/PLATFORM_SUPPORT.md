## 调用示例

```bash
curl -G 'http://39.106.202.228:8200/api/v1/interactions' \
  --data-urlencode 'media_name=车市号' \
  --data-urlencode 'url=https://cheshihao.cheshi.com/news/3589517.html'

curl -G 'http://39.106.202.228:8200/api/v1/comments' \
  --data-urlencode 'media_name=车市号' \
  --data-urlencode 'url=https://cheshihao.cheshi.com/news/3589517.html' \
  --data-urlencode 'page=1'
```

公开评论接口使用 `page` 页码继续读取；汽车头条仅支持 `page=1`。分页参数和批量调用见 [API 简明使用文档](API_QUICKSTART.md)。

- 回归测试 216 项通过；最终发布清单调整后，19 项专项检查再次通过。
- 对上述 29 个新增来源各取 1 个原始数据链接，关闭缓存，经过真实 API 路由和生产配置分别请求互动、评论：**58/58 次返回 HTTP 200**。
