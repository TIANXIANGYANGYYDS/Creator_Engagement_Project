  1. 一个上游响应同时包含互动量和评论内容时才能合并；详情接口、评论接口各调用一次时，按两次请求记录。
  2. IP 和请求不是一一对应：一个 IP 在有效期内可以承载多次请求，不能把 0.00084 元/IP 直接写成每次请求成本。
  3. 成本公式：新增代理 IP 数量 × 0.00084 元；平均请求成本再除以该批 IP 实际完成的成功请求数。
  4. 直连且未调用代理池时，IP 采购成本为 0。公众号 HTML 只有在同时预载统计和精选评论时，才属于同一响应获取两类数据。
  5. 验证码、代理失效或平台风控导致换 IP 时按实际新增 IP 计；服务器、存储、带宽、维护和人工登录成本不包含在内。
