## 本轮修复

1. 好看视频新增纯协议目标页 SSR 解析，补齐精确播放、点赞和评论数，并校验目标 `vid`。
2. 微博 `hotflow` 后续页跳登录时自动降级匿名 `api/comments/show?page=N`；纯表情评论保留 `img.alt`。
3. 小红书签名路径补齐 `x-xray-traceid/x-mns/xy-direction/x-rap-param`，HTTP 406 时从 `XYS_` 重试 `XYW_`。
4. 公众号新增 `preload_comment_list` 首屏解析；没有预载数据时仍严格遵守原生会话边界。
5. 浏览器评论链路改为先打开评论区，再滚动页面与弹层内部容器，避免只滚动外层页面而不
   触发深分页请求。
6. 本地登录命令扩展到八个平台，支持 `--url` 直接打开目标内容页；不接收账号密码或
   Cookie，状态只保存在 Git 忽略目录。
7. 浏览器兜底也严格区分互动量与评论：互动量请求不再点击或滚动评论区，减少无关请求和
   风控触发面。
8. 头条浏览器 SSR 只接受目标 `work_id` 对应的 document，推荐文章或 iframe 的计数不会
   再覆盖目标互动量。
9. 全量测试从 79 增至 85；八个平台 16 条首屏真实请求重新执行，7 个原样例通过，小红书
   失效样例换成当前公开笔记后互动量和首屏评论通过。

## 仍需外部条件的边界

- 公众号样例由作者关闭评论，无法用任何账号生成不存在的评论；开启评论的文章仍可能需要
  手机微信文章短时会话。
- 小红书游客态只验证首屏，深分页需要调用方自己的有效会话和 `xsec_token`。
- 微博匿名降级已覆盖本轮样例第 2 页；更深页仍可能 `ok=-100`，IP 池不能替代平台权限。
- 抖音、头条的部分计数和评论会受动态设备状态影响；空包或挑战会明确返回原因。
