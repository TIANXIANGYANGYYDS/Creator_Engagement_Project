## 请求隔离与资源保护实测

- 互动量和评论接口分别执行上游流程、分别缓存；只有相同接口、URL、媒体和页码的重复请求
  才复用 120 秒缓存，同时到达的完全相同请求只运行一个上游任务。
- 一次业务流程内连续 GET/POST 可共用一个代理租约，单元测试确认只取得和归还一个代理
  IP；这些 HTTP 调用仍按各自的上游请求数量记录。
- 全服务采集并发默认 4，浏览器并发默认 1，51 代理池默认 4、单 IP 并发 1；缓存最多 1000 项。
- 企业模式默认最多 3 次协议尝试。HTTP 200 业务空包、验证码和缺目标字段也会淘汰当前
  代理；失败结果不缓存，成功及可用部分结果仍缓存。
- 快手互动量和评论联合诊断 20.17 秒、峰值 RSS 411096 KB；其中包含页面导航、详情和评论
  等多个请求，不能记为一次请求。
- 抖音匿名纯协议联合诊断 1.93 秒、峰值 RSS 64680 KB，返回点赞 20303、评论总数 2909、
  首屏 20 条及下一游标 20；其中包含预热、访客初始化、详情和评论等多个请求。

完整成本公式和低内存参数见 [`COST_AND_CAPACITY.md`](COST_AND_CAPACITY.md)。

## 企业稳定模式最新实测

以下结果使用最终实现、业务缓存关闭、`MyAgent / Python 3.13.12`。快手使用 4 槽代理池、
每个 IP 单并发、最多 3 次协议尝试，4 个 benchmark worker、每秒最多启动 2 个业务调用；

## 仍需外部条件的边界

2026-08-24 对用户提供的两篇 CSDN 材料与其引用项目做了源码级复核：

- 视频号采集文章只提供返回 JSON 样例，没有请求端点、认证头、Cookie 来源、
  签名或可运行代码；它能证明该作者有一个带会话的供应端，不能证明公开网页可匿名返回评论。
- `wx_video` 文章所引项目与视频号采集无关，不能用于当前接口。
- 当前的视频号助手协议可在不启动浏览器时生成登录二维码。实测匿名
  `auth_login_code` 返回 HTTP 201、`errCode=0`和 token，Cookie 为空；真实账号扫码确认
  是服务端下发授权 Cookie 的必要条件。该后台评论接口使用自有作品
  `exportId`，不能替换任意公开 URL 的 `finderGetCommentList` 客户端会话。
- 再次直连统一评论接口：公众号样例返回 `no session`，并明确缺
  `uin/key/pass_ticket/appmsg_token`；视频号样例一次请求返回评论总数 4060，
  评论正文 0 条且 `coverage=unsupported`，未将总数误报为正文成功。

- 公众号匿名 `show_comment=0` 不能证明作者关闭评论。任意第三方文章现已实现 Cookie-only
  纯协议：自动化已验证字段恢复、互动请求、精选评论 buffer 分页、过期/脱敏/验证码分类。
  当前服务器没有用户提供的完整文章 Cookie，真实成功率和 P50/P95 必须等 Cookie 放入
  `.local/env/.env` 后再测，不能拿 mock 或匿名空结果伪装百测；IP 不能补齐缺失会话字段。
- 视频号互动量匿名可用；公开页只下发评论总数。任意视频评论正文需要微信视频号客户端
  `finderGetCommentList` 会话；侧车适配器已实现，未配置授权终端时纯服务端会明确返回
  `unsupported`。
- 小红书互动对带当前有效 `xsec_token` 的 URL 已达 100/100，无需登录；token 缺失或过期
  时不能仅凭 note ID 恢复。评论低频首屏为 20/20，深分页仍需要调用方自己的有效
  `web_session` 和 token。
- 微博匿名降级已覆盖本轮样例第 2 页；更深页仍可能 `ok=-100`，IP 池不能替代平台权限。
- 抖音已转为匿名签名协议，签名或访客规则变化时仍可能空包并进入浏览器兜底；头条部分
  计数仍受 SSR/挑战影响。

## 零账号一级评论分页结论（2026-08-25）

统一 `/comments` 接口只返回一级评论正文，每页最多 20 条，调用方根据 `next_page` 继续。
评论对象里的 `replies` 只是回复数量，不会触发额外请求。
全量自动化在 `MyAgent / Python 3.13.12` 下为 `173 passed`，`ruff check app tests` 通过。

| 分类 | 平台 | 结论 |
|---|---|---|
| 可翻到匿名公开末页 | 抖音、今日头条、好看、快手、B 站 | 均有公开游标或页码结束标志 |
| 可翻多页但不保证到底 | 微博 | 第 2 页已实测；更深页可能 `ok=-100` 或登录跳转 |
| 固定只能第一页 | 无 | 当前没有把任何平台误标为仅第一页 |
| 不能获取正文 | 微信公众号、微信视频号、小红书 | 严格零账号模式下明确返回 `unsupported` |

“公开末页”不含平台隐藏、删除、审核折叠或仅账号可见的评论，不能把页面显示的评论总数
简单等同于实际可返回的一级评论行数。
