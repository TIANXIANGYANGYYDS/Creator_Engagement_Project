## 请求隔离与资源保护实测

- 互动量和评论接口分别执行上游流程、分别缓存；只有相同接口、URL、媒体和页码的重复请求
  才复用 120 秒缓存，同时到达的完全相同请求只运行一个上游任务。
- 一次业务流程内连续 GET/POST 可共用一个代理租约，单元测试确认只取得和归还一个代理
  IP；这些 HTTP 调用仍按各自的上游请求数量记录。
- 全服务采集并发默认 4，浏览器并发默认 1，51 代理池默认 4、单 IP 并发 1；缓存最多 1000 项。
- 企业模式默认最多 3 次协议尝试。HTTP 200 业务空包、验证码和缺目标字段也会淘汰当前
  代理；失败结果不缓存，成功及可用部分结果仍缓存。
- 快手互动量和评论联合诊断 20.17 秒、峰值 RSS 411096 KB；其中包含页面导航、详情和评论
  等多个请求，不能记为一次请求。
- 抖音匿名纯协议联合诊断 1.93 秒、峰值 RSS 64680 KB，返回点赞 20303、评论总数 2909、
  首屏 20 条及下一游标 20；其中包含预热、访客初始化、详情和评论等多个请求。

完整成本公式和低内存参数见 [`COST_AND_CAPACITY.md`](COST_AND_CAPACITY.md)。

## 仍需外部条件的边界

- 公众号样例由作者关闭评论，无法用任何账号生成不存在的评论；开启评论的文章仍可能需要
  手机微信文章短时会话。
- 小红书互动对带当前有效 `xsec_token` 的 URL 已达 100/100，无需登录；token 缺失或过期
  时不能仅凭 note ID 恢复。评论低频首屏为 20/20，深分页仍需要调用方自己的有效
  `web_session` 和 token。
- 微博匿名降级已覆盖本轮样例第 2 页；更深页仍可能 `ok=-100`，IP 池不能替代平台权限。
- 抖音已转为匿名签名协议，签名或访客规则变化时仍可能空包并进入浏览器兜底；头条部分
  计数仍受 SSR/挑战影响。
