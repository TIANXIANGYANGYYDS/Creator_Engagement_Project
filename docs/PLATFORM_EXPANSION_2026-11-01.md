## 已修复的兼容与语义问题

- 上观的 shobserver/jfdaily 官方域名、爱集微旧 laoyaoba 分享 URL、同顺号 lgt 分享 URL、OFweek 子站 URL 已按明确格式接入。
- 新浪新闻社区从目标页恢复评论线程，支持 qcmnt 与 ds；文章 ID 与线程 ID 不同，不能混用。真实样本有 6 个公开根评论；page_size=2 的第 1、2 页返回不同 ID。
- 爱集微首屏省略 after_id；空字符串会触发业务错误 73，不能当零评论。正文来自 content，作者来自 user_info.nickname。
- 澎湃真实样本总数 4，pageSize=2，第 2 页 hasNext=false；仅返回根评论。foldNum 是展示折叠参数，不是回复数。
- AcFun 非空样本总评论 57、根评论 45，回复正文不返回；第一电动已验证含 1 条根评论的样本，BOM JSON 正常解析。
- 简书排除推荐文章的 23 万级阅读与作者统计；增长黑客排除作者总评论；玩车教授使用公开显示 1.4w 而不是内部 post_hits_real；观海不把未展示 pv=0 作为阅读。
- Nuxt 字面量状态仅解析 JSON 参数及引用，不执行网页脚本；非法调用表达式和未知变量被拒绝。
- 评论能力元数据区分尚未接通正文与已实现分页；仅零评论验收不宣称支持全部评论。
